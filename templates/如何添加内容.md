# 如何给《星河实验学园》添加内容

你不需要懂编程，也不需要重新打包。整个过程只有三步：

1. 用记事本打开桌面上的 **`校园内容.js`**
2. 把里面任意一个示例前面的 `//` 去掉，改成你想要的名字和数字
3. 保存文件 → 回到浏览器按 **F5 刷新** → 新内容就出现在游戏里了

> 游戏文件和 `校园内容.js` 必须放在**同一个文件夹**（桌面上的三个文件：`星河实验学园.html`、`校园内容.js`、`如何添加内容.md`）。
> 双击 `星河实验学园.html` 打开游戏即可。

> **这个文件只属于你自己**：`校园内容.js` 不会进入 git 仓库（仓库里只有公开模板 `public/校园内容.示例.js`），
> 所以你在里面加的内容不会被同步到 GitHub，放开了写。

### 先记住两件事：时间单位与数值规模

**① 所有时间字段的单位都是「游戏时间」。**

| 你在数据里写的天数 | 1× 速度下的现实时间 | 2× | 5× |
| --- | --- | --- | --- |
| 0.1 天 | 约 1 秒 | 0.5 秒 | 0.2 秒 |
| 1 天（= 1 440，即字段里的「分钟」数） | 12 秒 | 6 秒 | 2.4 秒 |
| 3 天 | 36 秒 | 18 秒 | 7.2 秒 |
| 30 天 | 6 分钟 | 3 分钟 | 1.2 分钟 |

所以 `baseBuildMinutes: 10000` 是 **6.9 天**，1× 下**约 83 秒**。**游戏界面里只会显示天数**，现实时间放在括号里，例如「6.9 天（约 83 秒）」——不会出现「游戏分钟」这种小单位，所以填数值时直接按「几天」来想就好（`baseBuildMinutes` 里 1 440 = 1 天）。

**② 资源数值规模**：开局每天收入约 **2 200 资金**，一次升级大概 2 500–10 000 资金。填数值时用「几个游戏日的收入」当尺子最方便：

| 效果 | 建议数值（早期） |
| --- | --- |
| 一次小升级的成本 | 2 000 – 5 000 资金 |
| 一次中型建筑 | 10 000 – 50 000 资金 |
| 事件里的代价/收益 | 300 – 3 000（资金或教学资源） |
| 事件带来的属性变化 | 满意度 / 压力等 ±2 – ±8 |

## 0. 先说三件事

**① 只改 `//` 开头的注释行。** 文件里每个示例都长这样：

```js
    // {
    //   id: 'teaCeremonyCourse',
    //   name: '茶道与礼法',
    //   ...
    // },
```

把每一行前面的 `// ` 删掉，它就变成真正生效的内容：

```js
    {
      id: 'teaCeremonyCourse',
      name: '茶道与礼法',
      ...
    },
```

想关掉某项，再把它前面的 `//` 加回去就行。

**② 检查逗号与引号。** 这是唯一容易犯的错：

- 每一项的结尾要有英文逗号 `,`
- 文字要用英文引号 `'...'` 或 `"..."`，不要用中文引号 `“ ”`
- 花括号 `{}` 与方括号 `[]` 要成对

写错了不会弄坏存档，游戏只会忽略这一项，并在控制台提示原因。

**③ 每次改完怎么确认生效了？**

- 打开游戏，进【选项】面板，最下面会显示：**外部内容：已加载 N 项**（N 变大就是成功了）
  如果显示「未找到校园内容.js，或文件里还没有启用任何内容」，说明文件没被读到或所有示例还是注释状态
- 或者按 **F12** 打开控制台，会看到 `[校园内容.js] 已加载，类别：…，条目数：N`
- 内容会出现在对应面板：课程 →【课程】、校规 →【校规】、科技 →【科技】、事件 → 触发时浮窗、建筑 →【建筑】、社团 →【社团】、活动 →【活动】
- 用 `requires` 写了前置条件的内容，会在条件达成时自动出现在**屏幕中央的「新解锁」弹窗**里（例如「由于『教学楼』落成，于是解锁了……」，并带上你写的 `desc`）。不需要额外配置，写好 `desc` 就等于写好了那条弹窗说明。

## 0.5 图标怎么配

每条内容的 `icon` 字段就是一个字符串，三种写法都支持：

| 写法 | 例子 | 说明 |
| --- | --- | --- |
| emoji（最省事） | `icon: '🍵'` | 推荐，直接复制下面的速查表 |
| 图片文件 | `icon: './icons/tea.png'` | 图片要和游戏 HTML 放同一文件夹（或它的子文件夹，如 `icons/`） |
| 内嵌图片 | `icon: 'data:image/png;base64,...'` | 绝对不会加载失败，适合发给别人 |

> 只写一个中文字也可以，例如 `icon: '茶'`，会当成文字显示。

### 用图片当图标

1. 把图片放到和 `星河实验学园.html` **同一个文件夹**，或者在里面新建一个 `icons` 子文件夹
2. 在内容里写相对路径：

```js
    {
      id: 'teaRoom',
      name: '茶室',
      icon: './icons/tea.png',        // 也可以写 'icons/tea.png'
      //  其余字段照常…
    },
```

3. 保存 → 刷新页面即可看到图标

要求与建议：

| 项目 | 建议 |
| --- | --- |
| 格式 | PNG、SVG、JPG、WebP、GIF 都行；**PNG / SVG（透明背景）最合适** |
| 尺寸 | 64×64 或 128×128，正方形；游戏里会缩放到 18–26 像素显示 |
| 命名 | 用英文或数字，避免空格与特殊符号，例如 `tea-room.png` |
| 文件大小 | 单张建议 50 KB 以内，太大只是拖慢加载 |

**如果图片不显示**（浏览器对本地文件的限制因版本而异），有三条路：

1. 确认路径拼写与大小写、文件确实在那个文件夹里
2. 换成**内嵌写法**，绝对可靠：在 PowerShell 里执行下面一行，把输出的一长串粘到 `icon:` 后面

```powershell
"data:image/png;base64," + [Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\路径\你的图标.png"))
```

3. 直接改回 emoji（最省事，效果也统一）

> 图片加载失败时游戏会显示 ❔ 占位，不会报错、不会破坏布局。`icon` 只影响显示，与任何数值无关。

## 1. 最快的验证：加一门课

打开 `校园内容.js`，找到 `courses: [` 那一段，把示例取消注释，改成这样：

```js
  courses: [
    {
      id: 'teaCeremonyCourse',           // 唯一 id，只能用字母数字下划线短横线
      name: '茶道与礼法',
      icon: '🍵',
      desc: '把手上的动作做完整，是这门课唯一的要求。',
      category: '特色课程',              // 基础课程 / 能力课程 / 特色课程 / 实验课程
      subject: 'arts',                   // 任课学科组：chinese / math / english / science / humanities / arts / info / psych
      teacherRequired: 1,                // 需要几名该学科教师
      slotCost: 1,                       // 占用几个课程槽位
      capacity: 60,                      // 能覆盖多少名学生
      teachingCostPerStudentMinute: 0.003,   // 每名学生每分钟消耗的教学资源
      growth: { arts: 0.012, morality: 0.01, satisfaction: 0.012, stress: -0.012 },  // 每天
      output: { culture: 6, parentTrust: 6 },                                        // 每天（按 40 人折算）
      requires: { buildings: { artsBuilding: 1 } },   // 前置：艺术楼 1 级
      tags: ['culture'],
    },
  ],
```

保存 → 刷新 → 去【课程】面板的「特色课程」页，就能看到《茶道与礼法》。建成艺术楼之后它就可以开课。

**数值参考量级**（不用精确，凭感觉填就行）：

| 字段 | 建议范围 | 说明 |
| --- | --- | --- |
| `growth` 主属性 | 0.01 – 0.035 | 每天成长；0.02 表示一年约 +7 |
| `growth.stress` | 0.02 – 0.06 | 正值加压，负值减压 |
| `teachingCostPerStudentMinute` | 0.0016 – 0.0052 | 越大越费教学资源（当前数据表就在这个区间；消耗按覆盖人数计算） |
| `output` 资源 | 2 – 26 | 每天产出，按覆盖人数折算 |
| `capacity` | 60 – 200 | 越大覆盖面越广 |

## 2. 加一条校规

```js
  policies: [
    {
      id: 'noPhoneInClass',
      name: '课堂手机集中管理',
      icon: '📵',
      desc: '上课期间手机统一放进储物柜。',
      category: '管理',                 // 教学 / 学生 / 管理 / 特色
      effects: [
        { target: 'exam_score', op: 'mul', value: 0.06 },         // 考试成绩 +6%
        { target: 'satisfaction_rate', op: 'mul', value: -0.05 }, // 满意度 -5%
      ],
      tags: ['管理'],
    },
  ],
```

`effects` 里每一条就是一条加成：

- `target`：作用目标（见下面第 8 节的常用表）
- `op: 'mul'`：百分比，`0.1` = +10%，`-0.05` = -5%
- `op: 'add'`：固定值，例如校规名额 `{ target: 'policy_slots', op: 'add', value: 1 }`

> 建议每条校规**同时有好处和代价**，这才是这个游戏的策略乐趣。

## 3. 加一个事件（会以居中浮窗弹出）

```js
  events: [
    {
      id: 'morningBell',
      title: '清晨的第一声铃',
      icon: '🔔',
      text: '开学第一个周一，老校钟比平时早了十分钟响。学生们站在操场上，没有人说话。',
      category: '校园',                 // 校园 / 学生 / 教师 / 比赛 / 季节 / 校友 / 外校 / 特殊
      weight: 10,                       // 抽取权重：越大越常出现
      cooldownDays: 20,                 // 触发后 20 个游戏日内不再出现
      seasons: ['spring'],              // 可选：只在春季出现（spring/summer/autumn/winter）
      choices: [
        {
          label: '让学生自己排升旗队',
          hint: '学生的积极性会提高',
          cost: { teaching: 300 },                  // 代价（会被扣掉）
          gain: { activity: 120, culture: 80 },     // 获得
          studentDelta: { satisfaction: 5, social: 2 },  // 学生变化
          notes: ['那天之后，升旗队每次都比铃声响得更早。'],
        },
        {
          label: '由教务处统一安排',
          hint: '稳妥但无趣',
          cost: { money: 600 },
          gain: { parentTrust: 20 },
          studentDelta: { satisfaction: -2, stress: 1 },
        },
      ],
    },
  ],
```

事件浮窗会自动把每个选项算成明细给你看（「代价：教学资源 -100／获得：学生活跃度 +60／学生：满意度 +5」），**你只要写数字，不用写说明**。

可选字段：

| 字段 | 作用 |
| --- | --- |
| `cost` | 消耗资源（会被扣除，注意这里只写正数） |
| `gain` | 获得资源 |
| `studentDelta` | 学生属性变化（可写 `academic / sports / arts / research / morality / social / health / creativity / stress / satisfaction`） |
| `teacherDelta` | 教师变化（`{ quality: 2, stress: -3, morale: 5 }`） |
| `notes` | 只用于日志的说明文字 |
| `effects` | 永久加成（例如 `{ target: 'festival_score', op: 'mul', value: 0.03 }`） |
| `schedule` | 延迟后续事件：`[{ eventId: '后续事件id', days: 3 }]` |
| `grantCards` | 额外给一次卡片三选一：`{ pool: 'campus', count: 3 }` |

**延迟事件**：写一个 `schedule`，再定义一个 `weight: 0` 的后续事件（`weight: 0` 的事件不会随机出现，只在排期到期时弹出）。

## 4. 加一栋建筑

```js
  buildings: [
    {
      id: 'greenhouse',
      name: '校园温室',
      icon: '🌱',
      desc: '生物社团的实践基地。',
      category: '科研',               // 教学 / 科研 / 生活 / 体育 / 文化 / 交流 / 行政
      baseCost: { money: 20000, teaching: 4000 },
      costGrowth: 1.35,               // 每升一级的成本倍数（1.3 ~ 1.4 比较合适）
      baseBuildMinutes: 10000,        // 1 级工期 = 10000 / 1440 ≈ 6.9 天（1× 下约 83 秒）
      buildTimeGrowth: 1.12,
      maxLevel: 20,
      clubSlots: 2,                   // 可选：提供几个社团部室
      courseSlots: 1,                 // 可选：提供几个课程槽位
      studentCapacity: 60,            // 可选：学生容量
      production: { research: 1.2 },  // 每分钟每级产出的资源
      storage: { research: 200 },     // 可选：每级提供的仓储上限（资金/教学/科研/体育/文化）
      storageGrowth: 1.5,             // 可选：仓储逐级 ×1.5（不写则按等级线性累加）
      perLevelEffects: [{ target: 'student_growth', op: 'mul', value: 0.004 }],
      requires: { buildings: { labBuilding: 1 } },
    },
  ],
```

前置条件可以写：`{ buildings: { 建筑id: 等级 }, tech: ['科技id'], schoolRating: 40, graduates: 100, totalClubLevels: 6 }`。

### 关于仓储上限

`资金 / 教学资源 / 科研点 / 体育点 / 文化点` 有存量上限，超出上限的产出会被浪费（游戏会提示）。开局资金上限约 5 250，相当于 2 个多游戏日的收入——所以挂机囤钱没有意义，该花就花。

内置了五座仓储建筑，你可以照着做自己的：

| 资源 | 建筑 |
| --- | --- |
| 资金 | 财务处（每级 +2 500，逐级 ×1.5） |
| 教学资源 | 教材库（每级 +700，逐级 ×1.5） |
| 科研点 | 仪器库（每级 +500，逐级 ×1.5） |
| 体育点 | 器材库（每级 +500，逐级 ×1.5） |
| 文化点 | 道具库（每级 +500，逐级 ×1.5） |

写自定义建筑时：

- `storage: { money: 2000 }` —— 该建筑 1 级提供的上限
- `storageGrowth: 1.5` —— 每级按倍数增长（专用仓储建筑建议 1.5；普通建筑不写，就是按等级线性累加）
- 科技 / 校规 / 传承节点也可以提升上限：`effects: [{ target: 'storage', op: 'mul', value: 0.2 }]` 表示全仓储 +20%

## 6. 加一个比赛 / 活动

### 6.5 加一支校队（队伍）

校队是「建筑 → 社团 → 招够人 → 上报成立 → 日常训练 → 打比赛」这条链的终点。在 `校园内容.js` 里用 `teams` 数组（工程内用 `addTeam`）：

```js
  teams: [
    {
      id: 'myKendoTeam',
      name: '星河·竹风',
      shortName: '剑道队',
      icon: '🥋',
      kind: '体育',                    // 体育 / 学术 / 艺术 / 科研 / 文化
      desc: '道场里的第一课是坐姿，第二课才是挥剑。',
      attribute: 'sports',             // 决定实力的学生属性
      requiresClub: { id: 'kyudo', level: 2, members: 20 },  // 需要哪个社团发展到什么程度
      requires: { buildings: { kyudojo: 1 } },               // 还需要什么建筑 / 科技 / 评级
      foundingCost: { money: 9000, teaching: 1200 },         // 上报成立的花费
      foundingActivity: 140,           // 需要的学生活跃度
      minStudents: 70,                 // 在校学生下限
      maxTierIndex: 5,                 // 可参加到第几级赛事（0=邻校友谊赛 … 5=国际邀请赛）
      baseStrength: 23,                // 成立时的初始实力
      training: {
        minutes: 1440,                 // 一次训练耗时：1440 = 1 天
        cost: { money: 900, teaching: 180 },
        baseGain: 5,                   // 基础收益，实际会乘以等级 / 属性 / 教师效率 / 士气 / 加成
        studentDelta: { sports: 0.016, stress: 0.02 },   // 训练对全校学生的长期影响
      },
      perLevelEffects: [{ target: 'competition_success', op: 'mul', value: 0.01 }],
    },
  ],
```

赛事阶梯是共享的（`src/data/teams.ts` 的 `TEAM_TIERS`）：邻校友谊赛 → 区级联赛 → 市级锦标赛 → 省级联赛 → 全国大赛 → 国际邀请赛，逐级提高实力门槛，后几级还需要对应科技（区域联赛 / 城市竞赛 / 全国赛事 / 国际课程项目）与学校评级。

想让训练更有效，可以写 `effects: [{ target: 'team_training', op: 'mul', value: 0.15 }]`。

```js
  activities: [
    {
      id: 'cityDebateCup',
      name: '全市辩论赛',
      icon: '⚖️',
      kind: '学术比赛',               // 体育比赛 / 学术比赛 / 艺术比赛 / 科研比赛 / 校园活动 / 校际交流 / 国际交流
      desc: '与全市高中同台论辩。',
      seasons: ['spring'],            // 可选：只在某些季节开放（spring / summer / autumn / winter）
      durationMinutes: 4320,          // 4320 = 3 天
      cost: { teaching: 1200, money: 2400 },
      studentCost: 16,                // 需要多少名学生
      attribute: 'social',            // 决定实力的学生属性
      difficulty: 60,                 // 越高越难（早期活动 30–60，全国级 100+）
      baseSuccess: 0.46,              // 基础成功率 0–1
      rewards: {
        reputation: 16,
```

## 8. 常用 `target`（加成目标）对照表

| target | 含义 |
| --- | --- |
| `money_rate` / `teaching_rate` | 资金 / 教学资源产出 |
| `research_rate` / `sports_rate` / `culture_rate` | 科研点 / 体育点 / 文化点产出 |
| `reputation_rate` / `activity_rate` / `parenttrust_rate` | 声望 / 活跃度 / 家长认可度 |
| `alumni_rate` / `fund_rate` / `intl_rate` / `influence_rate` | 校友贡献 / 教育基金 / 国际声誉 / 影响力 |
| `student_growth` | 所有学生成长速度 |
| `course_efficiency` / `course_cost` | 课程效率 / 课程教学资源消耗 |
| `teacher_efficiency` / `teacher_stress` / `salary` | 教师效率 / 教师压力 / 教师薪资 |
| `student_stress` / `satisfaction_rate` | 学生压力 / 满意度变化 |
| `exam_score` | 期末考与学年评定成绩 |
| `competition_success` / `competition_reward` | 比赛成功率 / 比赛奖励 |
| `club_effect` / `festival_score` | 社团效果 / 学园祭评分 |
| `build_cost` / `build_speed` | 建造与升级成本 / 建造速度 |
| `enrollment` / `student_capacity` | 招生人数 / 学生容量 |
| `tech_cost` / `legacy_cost` / `prestige_gain` | 科技成本 / 传承消耗 / 传承收益 |
| `policy_slots` | 校规名额（用 `op: 'add'`） |

完整列表（含中文说明）在游戏的 `src/game/types.ts` 的 `EFFECT_META` 里；写错的 `target` 会被忽略并在控制台提示。

## 9. 出错了怎么办

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 【选项】里显示「未找到校园内容.js」 | 文件不在游戏 HTML 旁边，或文件名不对；或所有示例都还是注释状态 | 确认两个文件在同一个文件夹且名字是 `校园内容.js` |
| 加载数量没变化 | 示例前面的 `//` 没删干净 | 把该示例每一行开头的 `// ` 都删掉 |
| 整份文件都不生效 | 少了逗号、用了中文引号、括号没闭合 | 按 F12 看控制台报错的行号，通常是「哪一行少了个逗号」 |
| 加载数量变大了，但面板里看不到 | 前置条件没满足（比如建筑的科技没解锁、课程需要的建筑没建） | 看内容的 `requires`；建筑与社团满足条件后才会显示 |
| 游戏的存档会不会坏？ | 不会 | 容错逻辑会跳过写错的内容并保留原存档；实在不放心可以先用【选项】→「导出 JSON」备份 |

## 10. 想改内置内容怎么办（进阶）

上面讲的是**新增**内容。如果你想**修改已有的**课程 / 校规 / 事件（比如改数值、改文案），需要改工程里的数据表：

```
src/data/courses.ts      课程
src/data/policies.ts     校规
src/data/technologies.ts 科技
src/data/events.ts       事件
src/data/buildings.ts    建筑与联动
src/data/clubs.ts        社团
src/data/activities.ts   比赛 / 交流 / 校园活动
src/data/achievements.ts 成就
src/data/legacy.ts       传承树
src/data/custom/index.ts 自己的新增内容（开发模式用）
```

改完在工程目录执行以下命令，然后重新把 `outputs/` 里的两个文件拷回桌面：

```bash
npm run build:single
npm test          # 可选：检查内容有没有写错
```

> 只在桌面玩的话，用 `校园内容.js` 新增内容就够了；`src/data/*` 这条路是给愿意动工程的人准备的。
