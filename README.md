# 星河实验学园（Xinghe Experiment Academy）

> 一款中文网页放置经营游戏：你是一所普通公立高中的校长。
> 从一栋旧教学楼、十五名教师和一百二十名学生开始，建设校园、安排课程、培养学生、制定校规、参加比赛、进行校际交流、应对随机事件，最终完成「学园传承」，把这一轮的经验带进下一所学校。

## 快速开始

```bash
npm install
npm run dev      # 开发服务器（默认 http://localhost:5173）
npm run build    # 类型检查 + 生产构建（输出到 dist/）
npm run build:single   # 打包成单文件 HTML（输出到 outputs/星河实验学园.html）
npm run preview  # 预览生产构建
npm test         # 运行全部自动化测试（Vitest）
```

构建产物是纯静态文件，可直接部署到 GitHub Pages 或任意静态服务器（`vite.config.ts` 中 `base: './'`，支持子目录部署）。不需要后端。

### 单文件版（可以放桌面双击打开）

```bash
npm run build:single
```

会生成 `outputs/星河实验学园.html`：**一个约 340 KB 的 HTML 文件**，JS 与 CSS 全部内联，没有任何外部引用。把它拷到桌面、U 盘或发给别人，双击即可在浏览器里玩，不需要网络也不需要服务器。

两点说明：

- 打包时会把脚本放到 `</body>` 之前（原本的 `type="module"` 自带 defer，内联成普通脚本后会变成同步执行，必须放在挂载点之后）。
- 部分浏览器在 `file://` 下禁止 `localStorage`，此时游戏仍可正常运行，但不会自动保存。用【选项】里的「导出 JSON / 压缩串」把存档复制出来备份，下次用「导入存档」恢复即可；【选项】面板也会显示这条提示。想让自动保存生效，就用 `npm run dev` 或放到任意静态服务器上打开。

## 自定义内容（不改引擎）

**最简单的方式（桌面上就能改，不用重新打包）**：把游戏 HTML 与 `校园内容.js` 放在同一个文件夹，直接在 `校园内容.js` 里写内容，保存后刷新页面即可。格式说明、逐字段示例与排错表见 [如何添加内容.md](templates/如何添加内容.md)（打包时会和游戏一起生成到 `outputs/`）。游戏内【选项】面板底部会显示「已加载 N 项」，按 F12 也能用 `academy.content()` 查看加载情况。

**改工程里的方式**：编辑下面这个文件（开发模式用）：

```
src/data/custom/index.ts
```

在 `registerCustomContent()` 里按注释例子调用 `addBuilding / addSynergy / addCourse / addClub / addTech / addPolicy / addEvent / addCard / addActivity / addAchievement / addLegacyNode` 即可，保存后刷新页面就生效：新建筑会自动出现在【建筑】、新社团出现在【社团】、新科技出现在【科技】、新事件进入随机事件池；读取旧存档时会自动补齐这些条目。

字段说明、完整示例与排错表见 [自定义内容指南](docs/CUSTOM_CONTENT.md)。两种方式共用同一套注册接口与内容自检（重复 id、加成目标拼写、前置 id、科技循环依赖都会在启动与 `npm test` 时检查）。

## 立即试玩要点

1. 打开页面后你会看到左侧校园信息、中间校园主视图、右侧资源与学生状态。
2. 到【课程】开设「语文」「数学」——学生属性才会开始增长。
3. 到【建筑】扩建「教学楼」（课程槽位 + 容量）与「宿舍」（学生容量）。
4. 资源积累后研究【科技】，会解锁新建筑、新课程、新校规。
5. 学生属性提升后到【比赛】派队伍参赛，胜负都会带来声望，成功有概率获得效果卡（三张选一张）。
6. 一年之后会触发学年结算：升学、毕业、校友转化、新生入学、教育基金拨付与年度报告。
7. 到【社团】成立动漫社、轻音社、超自然研究社等部活；建筑（音乐教室、艺术楼、大礼堂、游泳馆、弓道场、天文台、创客实验室）与科技会陆续解锁更多社团。
8. 社团等级会累积「学园祭评分」，解锁【活动】里的学园祭（文化祭）、体育祭、合唱祭等祭典活动。
9. 评级 ≥ 52 且累计毕业生 ≥ 200 时，可以在【传承】结束这一轮并获得传承点。

调试工具：在网址后加 `?debug=1`（或执行 `localStorage.debug = '1'`），页面会出现调试面板，并在 `window.academyDebug` 暴露 `unlockAll / addAll / build / advanceYear / triggerEvent / prestige / giveCard` 等接口。

## 已完成的系统（第一版可玩版本）

**核心引擎**

- `GameState` + `GameEngine` + `GameLoop`：真实时间驱动，1× 速度下 1 真实秒 ≈ 0.08 游戏日（1 游戏日 ≈ 12 秒，1 学年 ≈ 72 分钟），支持 1× / 2× / 5× 与暂停。界面里的时长统一写成「游戏天数（现实时间）」，例如「2.4 天（约 25 秒）」，不会再把游戏时间误读成现实时间。
- 时间系统：学年 → 学期 → 月份 → 日期 → 季节，季节具有真实修正（春招生、夏体育、秋科研文化、冬考试与压力）。
- **评级考核**：评级不再自动上涨——每次跨档都要经过评估组的现场考核（8 档、7 次考核，各有剧情、清单与奖励）；学校从「待整改高中」起步。
- 资源系统：12 种资源分基础 / 中期 / 后期三档，每种资源都有独立作用与来源，并提供带明细的产出 Tooltip。
- 加成系统（`ModifierIndex`）：建筑、建筑联动、科技、校规、效果卡、传承、事件永久加成、季节与学校评级全部汇总到统一索引，公式层只读取聚合结果。
- 建造系统：成本随等级指数增长（1.35 左右）、工期按造价开方推导（越贵越久）、3 个并行工位、建造队列与取消退款。
- 存档系统：自动保存（默认 30 秒）、手动保存、JSON / base64 导出、导入、版本迁移、坏档修复与备份槽。
- 【选项】里提供三种重置档位：`手动保存`、`重新开始本轮`（保留传承树 / 成就 / 统计）、`清空全部存档`（连带删除本地主存档与备份，把学园进度、传承点、传承树、成就、统计与设置全部恢复为初始状态，需要二次确认）。
- 离线结算：按上限与效率折算，不会出现数值爆炸。

**内容系统（数据驱动）**

- 建筑 31 种（教学 / 科研 / 生活 / 体育 / 文化 / 交流 / 行政），每栋都提供容量、课程槽、部室、效果或产出中的至少一项，并有 16 组建筑联动。
- 课程 35 种（基础 / 能力 / 特色 / 实验），包含教师需求、容量、教学资源消耗、成长与产出、季节加成。
- 科技 49 项，五个分支且存在前置关系与循环依赖检测（含部活运营 → 学园祭筹办 → 全国社团大会）。
- 校规 23 条，名额有限，每条都有明确代价（含部活必修、文化祭停课筹备）。
- 随机事件 49 个，含季节性事件、条件事件与延迟多阶段事件（教师科研项目、校舍维修、学园祭筹备、后夜祭）。
- **事件以居中浮窗出现**，每个选项都自动列出「代价 / 获得 / 学生变化 / 教师变化 / 永久加成 / 延迟后续 / 额外卡片」明细（由真实结算逻辑反推，不会与实际效果脱节）；处理时间宽裕：至少 5 分钟现实时间，暂停时不会自动结束。
- 奖励效果卡 40 张（普通 / 稀有 / 史诗 / 传奇），三选一获取，含时长型与次数型效果。
- 比赛、交流与校园活动 24 项：体育 / 学术 / 艺术 / 科研比赛、校际 / 国际交流，以及学园祭（文化祭）、体育祭、合唱祭、潜水社合宿、修学旅行、全国社团大会；成功率由属性、教师效率、学园祭评分与各类加成对抗难度决定。
- **社团（部活）28 个**：动漫社（漫画研究部）、轻音社（軽音部）、超自然研究社（オカルト研究部）、潜水社（ダイビング部）、弓道社、茶道社、料理社、将棋社、铁道研究会、应援团、学生会……占用部室与社员名额（允许兼部），每天消耗运营资金，换来属性成长、资源产出与学园祭评分；随建筑 / 科技 / 评级逐步解锁。
- **校队（队伍）17 支**：篮球 / 足球 / 田径 / 游泳 / 弓道 / 数学 / 科学 / 信息学 / 乐队 / 合唱 / 演剧 / 美术 / 天文 / 将棋 / 电竞 / 机器人 / 辩论。队名由**学校名 + 后缀**生成（学校叫「星丘」就推荐「星丘火鸟队」这类名字），可从 6 个备选里挑，也可以自己写、随时改名。解锁链是「建筑 → 社团 → 社团等级与人数 → 上报成立校队」，之后靠**日常训练**积累实力，沿「邻校友谊赛 → 区级 → 市级 → 省级 → 全国 → 国际邀请赛」的赛事阶梯往上打；配套退役赛、队内恋爱、首胜、器材预算等剧情事件。
- **15 章剧情引导**：新存档与每次学园传承后，用故事一章一章介绍系统（一封信 → 只剩几位老师 → 第一张课表 → 校规 → 校园事件 → 校队 → 传承……），开局只开放【总览】【建筑】【选项】；浮窗上有「不再显示教程」，【选项】里可随时重开，关掉后系统仍会照常解锁。
- **任务面板**：左栏常驻「🧭 剧情引导」卡片，显示当前章节、该做什么、以及一键前往；剧情走完换成老校长的寄语。剧情引导期间只派发剧本事件（「开学第一周」），处理完第一件事件后随机事件才恢复。
- **现实时间速率**：顶栏与资源面板的「+x/分钟」都按现实时间显示（鼠标移到顶栏的 💰 / 📚 可展开每一项来源）；资源同时受仓储上限约束。
- **新解锁弹窗**：建筑落成 / 科技完成 / 评级通过 / 社团挂牌之后，会用一段校园味的剧情句在屏幕中央告诉你「由于做了什么，于是解锁了什么」（列出建筑 / 课程 / 科技 / 校规 / 活动 / 社团，一句话说明），文案模板在 `src/game/engine/UnlockEngine.ts`。
- **弹窗统一 0.3 秒淡入淡出**；仓储到顶不再弹提醒，只在右栏资源面板显示「⚠ N 项接近上限」。
- **界面大小**：默认 175%（高分屏友好），在【选项】→「界面大小」里可选 100% – 250%，效果等同于浏览器 Ctrl+滚轮缩放；断点按缩放后的等效宽度判断，放大后仍是三栏布局。
- 资源速率全部按**现实时间**显示（每分钟 / 每秒），与仓储上限、离线收益的单位一致。
- 成就 57 项（普通 / 隐藏 / 长期 / 极难），全部带实际奖励（含部活王国、全员部活、学园祭的名片、后夜祭的传说）。
- 传承树 39 个节点、7 个分支，含 7 个「传承特性」永久能力（含「学园祭传统」）。
- 学生系统：三个年级群体 + 聚合属性（学术、体育、艺术、科研、品德、社交、健康、创造力、压力、满意度），毕业 → 校友 → 影响下一轮。

**界面**

- 左 / 中 / 右三栏 + 底部导航，渐进式解锁（学生、科技、校规、比赛、交流、事件、传承、成就、统计依次开放）。
- 校名随时可改：【选项】里有「校名」面板（输入框 + 改名/还原 + 6 个推荐名），改完立即生效并写入存档，浏览器标签页标题也会跟着变。
- 建筑 / 课程 / 科技 / 校规面板采用紧凑列表：**每行只有图标、名称、状态与一个按钮**（建造 / 升级 / 开课 / 研究 / 施行），鼠标移上去才展开全部细节（描述、成本拆分、产能、效果、前置条件、剩余工期）。
- 未解锁的建筑（前置科技或前置建筑未满足）不会提前显示，满足条件后自动出现。
- 悬浮提示通过 Teleport 渲染到 body 并自动避让屏幕边缘，不会被滚动容器裁剪；所有关键数值都有明细（资源产出来源、评级构成、比赛成功率、成本拆分等）。
- 响应式布局，窄屏自动切换为单列。

## 尚未完成 / 已知限制（明确标记）

- **音效与音乐**：仅保留设置项，未接入音频资源（`settings.soundEnabled` 为占位）。
- **动画**：只有基础过渡与进度条动画，没有建造动画、学生活动等表现层内容。
- **事件数量**：40 个事件覆盖了所有分类，但重复游玩时仍会见到重复事件（冷却期较长，`once` 事件较少）。
- **比赛战术层**：目前只能选择「派不派队伍」，没有进一步的阵容 / 战术选择（已预留 `studentCost` 与属性维度）。
- **校友个体**：校友是统计量 + 质量系数，没有独立的「名人校友」名单与生涯模拟。
- **移动端**：布局可用，但没有专门的移动端手势与抽屉式导航。
- **成就进度**：成就只在达成时判定，界面不显示「当前进度 / 目标」。
- **数值平衡**：见 `docs/BALANCE.md`，评级 70+ 之后的成长曲线仍需要真实玩家数据校准。

## 放到 GitHub / GitHub Pages

仓库里已经带了 `.github/workflows/deploy-pages.yml`：推到 `main` 之后会自动跑测试、打包单文件版，并发布到 GitHub Pages。

```bash
# 1. 在 GitHub 上新建一个空仓库（不要勾选 README / .gitignore），拿到形如
#    https://github.com/<你的用户名>/<仓库名>.git 的地址

# 2. 关联远程并推送
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main

# 3. 打开仓库页面 → Settings → Pages → Source 选「GitHub Actions」
#    之后每次 push 都会自动更新，游戏地址是：
#    https://<你的用户名>.github.io/<仓库名>/
```

只想要一份能直接玩的网页文件：仓库里的 `outputs/星河实验学园.html` 就是单文件版，下载后双击即可，也可以丢到任意静态服务器。
