# 游戏设计：星河实验学园

## 一、身份与世界观

玩家是一所普通公立高中的校长。学校历史不短、名声不大，教学楼是三十年前的老房子，教师队伍勉强够用。你要做的事情很朴素：把这所学校办成一所真正像样的高中。

学园从一栋旧教学楼、一栋食堂、一栋宿舍、一个操场、十五名教师和一百二十名学生开始。每一轮经营都以「学园传承」收尾，把经验带进下一所学校。

## 二、核心循环

```
建设校园 → 产生资源 → 安排教学 → 培养学生 → 解锁科技
  → 解锁建筑 / 课程 / 校规 / 交流 → 参加比赛与活动 → 获得效果卡
  → 学校声望提升 → 学年结算（升学 / 毕业 / 校友）
  → 评级提高 → 达成阶段目标 → 学园传承 → 永久成长 → 下一轮
```

玩家在每个时刻都在做这几类决策：

1. 现在建设什么（教学楼还是宿舍？科研中心还是体育馆？）
2. 优先发展教学、学生、设施还是声望？
3. 这个学期开哪些课（槽位有限、容量有限）
4. 是否承担短期风险换长期收益（竞赛训练课程、精英培养校规）
5. 是否派出学生参加比赛 / 交流（消耗资源、影响压力与满意度）
6. 随机事件怎么处理（延迟事件还要决定是否追加投入）
7. 什么时候发起学园传承
8. 传承点永久强化什么（流派选择）

## 三、时间系统

- 结构：**学年 → 学期 → 月份 → 日期 → 季节**。一学年 12 个月、每月 30 天，开局为第 1 学年 9 月 1 日（秋季开学）。
- 学期：9 月 — 1 月为第一学期，2 月 — 7 月为第二学期，8 月为暑假。学年结算发生在进入 9 月时。
- 速度：1× 速度下 1 真实秒 ≈ 0.08 游戏日（1 现实分钟 ≈ 5 游戏日）；1 游戏日 ≈ 12 秒真实时间，1 学年（360 天）≈ 72 分钟，5× 下约 14 分钟。
- 单位约定：数据表里的 `baseBuildMinutes`、`researchMinutes`、`durationMinutes` 都是**游戏时间（内部按游戏分钟存）**，但界面**只用「游戏天数」表示时长**，并把现实时间放在括号里，例如「2.4 天（约 25 秒）」——不再出现游戏分钟 / 游戏小时这类小单位。1× 下 `1 现实秒 = 120 游戏分钟`。

季节不只是颜色，每个季节都有全局修正与事件权重：

| 季节 | 月份 | 教学重点 | 主要修正 |
| --- | --- | --- | --- |
| 春季 | 3-5 | 招生、社团招新、校园建设 | 招生 +15%、满意度变化 +10%、建造速度 +5% |
| 夏季 | 6-8 | 体育、社团、夏令营、暑期课程 | 体育产出 +20%、比赛成功率 +4%、事件更频繁 |
| 秋季 | 9-11 | 学园祭（文化祭）、学术竞赛、科研、文化活动、学年评价 | 科研 +15%、文化 +15%、比赛奖励 +6% |
| 冬季 | 12-2 | 期末考试、年度总结、奖学金 | 考试成绩 +10%、资金产出 -8%、学生压力 +15% |

月度节点：1 月触发期末考结算（学术能力 → 家长认可度与教育基金，同时带来压力）；3 / 6 / 9 / 12 月播放季节切换提示并给予相应资源。

### 仓储上限（存量管控）

学校能存放的东西是有限的：`资金 / 教学资源 / 科研点 / 体育点 / 文化点` 都有存量上限，**超出上限的产出会被浪费**（界面在资源条上显示「当前 / 上限」，接近上限时标黄并提示）。

```
仓储上限 = (基础容量 + Σ 建筑提供的仓储) × (1 + 仓储加成)
```

- 基础容量：资金 5 000、教学资源 800、科研点 400、体育点 400、文化点 400
- 附带存放空间：教学楼（教学 +150/级）、图书馆（教学 +250、科研 +60）、食堂（资金 +250）、实验楼（科研 +120）、大礼堂（文化 +400）等 27 栋建筑各有一点
- 专用仓储建筑（每级 ×1.5 增长）：**财务处**（资金 +2 500）、**教材库**（教学 +700）、**仪器库**（科研 +500）、**器材库**（体育 +500）、**道具库**（文化 +500）
- 仓储加成：科技「后勤自动化 +30% / 财务审计 +25% / 现代治理 +15%」、校规「物资与预算管理 +25%」、管理传承「仓储管理经验 +5%/级」、成就与事件也提供少量加成

设计意图：

1. **挂机不再等于白拿钱**——开局资金上限约 5 250，只相当于 2 个多游戏日的收入，囤满了就不再增加；
2. **事件与升级的花费有了重量**——罚款、临时支出会真的挤占预算；
3. **仓储成为一条独立的建设线**——想建更贵的楼，就得先把财务处 / 教材库做起来；
4. **离线前值得做决策**——离线收益同样受上限约束，出门前先花一波或先扩容。

声望、活跃度、家长认可度、校友贡献、教育基金、国际声誉、影响力属于评价类指标，不设上限。

## 五、学生系统（本作的核心差异点）

学生不是几千个独立个体，而是「**群体模拟 + 少量代表性个体**」：

- 三个年级群体（高一 / 高二 / 高三）各自拥有独立人数与聚合属性。
- 聚合属性：学术、体育、艺术、科研、品德、社交、健康、创造力，以及压力与满意度。
- 每年 9 月学年结算：高三毕业并转化为校友；高二升入高三；高一升入高二；新生按招生公式入学（受容量限制）。
- 新生基础属性远低于在校生，因此「不持续投入教学，平均水平就会下滑」是真实的压力来源。
- 校友以「活跃校友数量 + 校友质量系数」结算，影响校友贡献收入、校友事件与长期声望。

## 六、教师系统

教师以「教师队伍」形式管理，分为八个学科组：语文、数学、外语、理科、文科、艺体、信息、心理。

每组拥有：人数、教学能力、压力、士气。派生指标是**教师效率**，它会乘进课程效果、比赛指导与培养质量。教师效率 1.0 附近为常态；休息室、培训中心、科技与传承可以把它推高到 2.0 以上。

课程对教师有具体需求（例如数学竞赛训练需要 3 名数学教师）。教师不足时课程仍会开，但效果按比例下降。

## 七、建筑与联动

建筑由数据表驱动（`src/data/buildings.ts`），每栋至少提供一种非数值功能：容量、课程槽、解锁、事件条件或特殊被动。

建筑之间存在联动（`SYNERGY_DEFS`）：教学楼 + 图书馆提高课程效率、实验楼 + 科研中心提高科研产出、宿舍 + 食堂提高满意度、国际交流中心 + 图书馆提高交流成功率、校友中心 + 荣誉展览馆提高校友贡献等。

建造队列同时支持 3 个工位，取消时退回六成投入。

## 八、科技树

五个分支：教学科技、科研科技、学生发展、校园管理、对外交流，共 45 项，存在前置依赖（例如 现代教学 → 分层教学 → 智慧课堂 → 项目制学习 → 个性化教育）。

科技可以直接解锁建筑、课程、校规与活动，并修改公式（成本、产量、成功率、容量、校规名额……）。

## 九、校规

校规是策略层：名额有限（初始 2 条，可由「现代治理」科技与校史传承扩充），每条都有明确代价。例如「体育优先」提高体育产出与健康但压低学术效率；「精英培养」提高考试成绩却显著降低满意度；「考试强化」带来高分与巨大压力。不同组合形成不同流派：竞赛强校、快乐校园、科研立校、精英学校、国际路线。

## 十、比赛与校外交流

24 项活动分为体育、学术、艺术、科研比赛、校际 / 国际交流，以及校园活动（学园祭、体育祭、合唱祭、潜水社合宿、修学旅行、全国社团大会）。每项有耗时、学生需求、资源成本、难度、奖励与解锁条件。

成功率不是固定值：

```
队伍实力 = 对应学生属性 × (0.7 + 教师效率 × 0.6) × 相关加成（比赛或交流）
成功率 = 基础成功率 + (队伍实力 - 难度) / max(20, 难度) × 0.55   （限制在 3% ~ 97%）
```

成功分为「成功」与「大成功」（奖励 ×1.75）；失败也带回 25% 奖励，但学生压力上升。成功有概率获得效果卡（三张选一张）。

## 十一、社团（部活）与学园祭

### 课程覆盖模型（重要）

课程之间是**并行**关系，不是「先到先得」：语文、数学、英语各自独立覆盖全校学生——真实高中里学生本来就同时上这些课。
真正限制开课的是四件事：

1. **课程槽位**：同时能开几门课（教学楼、图书馆、信息中心、艺术楼等提供）；
2. **教师人数**：学科教师不足时该课效果按比例下降；
3. **平行班容量**：`有效容量 = 课程容量 + 60 × (教学楼等级 − 1)`，学生数超过容量时只有一部分学生能上这门课（面板会提示「教室不足」）；
4. **教学资源**：消耗按覆盖人数计算，开课越多、学生越多消耗越大；不够时课程继续但效果按 `0.4 + 0.6 × 可负担比例` 下降（面板显示「消耗 / 产出」对比）。

精英课程（例如数学竞赛训练，容量 60）天然只覆盖一部分学生，这是设计意图。

校园氛围主要由两部分支撑：**部活**与**祭典**。它们不是装饰，而是有数值意义的系统。

### 社团（部活）

游戏内置 28 个社团，覆盖文化、运动、学术、兴趣、特殊五类，例如：

| 社团 | 日式名 | 解锁条件 | 主要作用 |
| --- | --- | --- | --- |
| 动漫社 | 漫画研究部 | 教学楼 L1 | 艺术 / 创造力成长，文化点与活跃度 |
| 轻音社 | 軽音部 | 音乐教室 L1 | 艺术成长 + 满意度，学园祭评分高 |
| 超自然研究社 | オカルト研究部 | 图书馆 L1 | 让随机事件更频繁也更正面，学园祭评分极高 |
| 潜水社 | ダイビング部 | 游泳馆 L1 | 体育 / 健康成长，可解锁「潜水社合宿」 |
| 弓道社 | 弓道部 | 弓道场 L1 | 体育 + 品德 + 减压 |
| 茶道社 | 茶道部 | 艺术楼 L1 | 满意度与家长认可 |
| 料理社 | 料理部 | 料理教室 L1 | 满意度、健康，并直接产出资金 |
| 铁道研究会 | 鉄道研究会 | 社团活动楼 L2 | 活跃度与特殊事件 |
| 应援团 | 応援団 | 体育馆 L1 | 体育比赛成功率 |
| 学生会 | 生徒会 | 学生自治科技 | 满意度、学园祭评分最高 |

社团的运行规则：

- **部室**：社团数量受部室容量限制（教学楼每级 +1，社团活动楼每级 +6，部室栋每级 +8，中庭广场每级 +4）。
- **社员**：每级社团占用一定社员名额，总额上限为在校学生的 120%（允许「兼部」）。
- **运营成本**：每级每天消耗资金，因此社团扩张必须与收入同步。
- **收益**：社员带来属性成长与资源产出（按社员规模折算），并贡献学园祭评分。
- **解锁节奏**：全部依赖建筑 / 科技 / 评级 / 学年条件，因此是随游戏进程一层层打开的——先有教室和图书馆，才有动漫社与超自然研究社；先有游泳馆，才有潜水社。

### 学园祭与祭典

每个社团每级都会贡献**学园祭评分**，评分决定祭典类活动的成功率与奖励（最多 +40%）：

```
学园祭评分 = Σ(社团祭典贡献 × 等级) × 学园祭加成（中庭广场 / 学园祭筹办科技 / 校规 / 传承）
祭典加成 = min(学园祭评分 / 300, 40%)
```

祭典类活动（属于「校园活动」）：

**招生也在这里**：招生宣讲会、校园开放日、招生简章投放都属于「校园活动」，并且只在 **春季** 开放（`seasons: ['spring']`）。
它们不打比赛，而是累积**招生加成**（`rewards.recruitBonus`），在学年结算时直接计入下一年的新生人数：

```
新生人数 = (基础 46 + 声望×0.35 + 家长认可度×0.12 + 招生加成) × 招生加成倍率
          再受「学生容量 − 在校人数」限制
```

成功会拿满招生加成，大成功 ×1.75，失败也带回 25%（发出去的简章不会白费）。学生面板会显示当前累积的招生加成。
> 设计原则：招生是「办活动」，不是「上课」——学生不会去上「招生宣传课」，所以它不会出现在课程表里。

- **学园祭（文化祭）**：需要「学园祭筹办」科技与社团等级总和 ≥ 6，秋季举办，奖励声望、文化点、活跃度、资金与家长认可，并解锁成就「学园祭的名片」。
- **体育祭**、**合唱祭**：中等规模，分别偏体育与艺术。
- **潜水社合宿**：需要潜水社 Lv.2 + 游泳馆。
- **修学旅行**：需要评级 44 以上，大幅提升满意度与家长认可。
- **全国社团大会**：需要「全国社团大会」科技与社团等级总和 ≥ 25。

配套事件进一步强化氛围：社团联合招募周、部室分配争执、轻音社的首次演出、超自然研究社的调查、潜水社的器材、学生会选举、学园祭筹备会议、后夜祭、学园祭当天暴雨。其中后夜祭的选择会写入隐藏成就「后夜祭的传说」。

## 十一·五、校队（队伍）与赛事体系

社团是「兴趣组织」，校队是「代表学校出去比赛的队伍」。两者接在一起，构成校园体育与竞赛的主线。

### 解锁链：建筑 → 社团 → 招够人 → 上报成立

每支校队都有一条明确的成立路径，例如：

| 校队 | 成立路径 |
| --- | --- |
| 🏀 星河·火鸟（篮球队） | 体育馆 → 球技社 Lv.2 且社员 ≥ 30 人 → 上报成立 |
| 🎸 星河·轻音（轻音乐乐队） | 音乐教室 → 轻音社 Lv.3 且社员 ≥ 30 人 → 上报成立 |
| 📐 星河·欧几里得（数学竞赛队） | 教学楼 Lv.3 → 数学研究社 Lv.1 且社员 ≥ 16 人 → 上报成立 |
| 🤿 星河·海豚（游泳队） | 游泳馆 → 潜水社 Lv.1 → 上报成立 |
| 🦾 星河·齿轮（机器人队） | 创客实验室 Lv.2 + STEM 科技 → 机器人社 Lv.2 → 上报成立 |

共 17 支校队，覆盖体育（篮球 / 足球 / 田径 / 游泳 / 弓道）、学术与科研（数学 / 科学 / 信息学 / 机器人 / 天文 / 将棋）、艺术与文化（轻音 / 合唱 / 演剧 / 美术 / 辩论 / 电竞）。

### 日常训练

- 每支队伍有独立的**实力**与**士气**，实力只能靠训练与比赛积累。
- 一次训练消耗经费并占用 1–2 个游戏日，完成后按下列因素结算收益：

```
训练收益 = 基础收益 × (1 + 0.15 × (队伍等级 − 1)) × 士气系数 × 教师系数 × 队员属性系数 × 训练加成
```

- 训练同时会影响全校学生（例如运动队训练提升体育与健康、略微增加压力）。
- 士气会缓慢回升，输球不会永久打击队伍；**扩编**（Lv.1→5）提高训练收益与比赛加成。

### 赛事阶梯

所有校队共用一条阶梯，从邻校友谊赛一路打到国际邀请赛：

| 层级 | 实力门槛 | 对手强度 | 参赛资格 |
| --- | --- | --- | --- |
| 邻校友谊赛 | 18 | 24 | 无 |
| 区级联赛 | 30 | 40 | 科技：区域联赛 |
| 市级锦标赛 | 46 | 60 | 科技：城市竞赛 + 评级 40 |
| 省级联赛 | 68 | 85 | 评级 52 |
| 全国大赛 | 95 | 115 | 科技：全国赛事 + 评级 62 |
| 国际邀请赛 | 130 | 150 | 科技：国际课程项目 + 评级 72 |

胜负由「队伍实力 vs 对手强度」决定（胜率显示在界面上），胜利提升实力与士气并解锁更高层级的记录，失败也积累经验，但打击士气。

### 队伍剧情事件

队伍不只是数值，还有故事：**高三队员的退役赛**（办正式退役赛 / 简单送别 / 请她们留任助理教练）、**队服里的信**（青春恋爱：当作不知道 / 找班主任谈话 / 定队规）、**队史上的第一场胜利**、**队服与器材预算**。这些事件会改变队伍实力、士气与全校学生状态，选项的代价与后果都会在浮窗里列清楚。

## 十二、效果卡

40 张效果卡分普通 / 稀有 / 史诗 / 传奇四档，来源卡池不同（学术、体育、艺术、科研、交流、校园、通用）。卡片有两种：

- **时长型**：持续若干游戏日，例如「灵感爆发」12 小时科研 +100%。
- **次数型**：消耗使用次数，例如「名校交流经验」未来 5 次交流成功率 +15%。

每次获得都是**三选一**，因此带取舍而不是纯抽奖。

## 十三、随机事件与延迟事件

40 个事件覆盖校园、学生、教师、比赛、季节、校友、外校、特殊八类。事件按权重抽取，并受季节、学年、建筑、科技、校规与冷却期过滤。

**事件浮窗**：事件触发时会以居中弹窗出现（不是只躺在右侧列表里）。同时有多个待处理事件时按触发顺序依次弹出，点「稍后处理」或点遮罩可以把浮窗收起，事件仍保留在【事件】面板与右侧「进行中」里；一直不处理才会自动按保守方案结束。

### 弹窗与提醒

**界面大小（高分屏）**：整个界面按 `--ui-scale` 缩放（等价于浏览器 Ctrl+滚轮缩放），默认 **175%**，可在【选项】→「界面大小」里选 100% / 125% / 150% / 175% / 200% / 250%。实现方式是 `.app { transform: scale(var(--ui-scale)); width/height: 100%/scale }`（见 `styles.css`），字号、间距、按钮一起变大；因为缩放后媒体查询不再可靠，三栏 → 一栏的响应式断点改由 `App.vue` 按「缩放后的等效宽度」（`innerWidth / uiScale`）打 `data-narrow` / `data-tight` 标记。

**移动端适配**：`App.vue` 在挂载与 resize / orientationchange 时检测「窗口 ≤ 820px 或触屏且 ≤ 1024px」，命中就给根节点打 `data-mobile`，同时：

1. **忽略桌面倍率**（`--ui-scale` 强制为 1）——否则桌面默认的 175% 会把手机可用宽度压到 220px 左右，界面完全没法用；
2. 三栏 → 单栏滚动（复用 `data-narrow` 规则），`.grid` 一律单列，面板与内边距收紧；
3. 按钮、紧凑条目加大到手指点得中（`.btn` 抬高到 8×14，`.btn.small` 6×11），底部导航贴底、不透明、`env(safe-area-inset-bottom)` 避开手势条；
4. **悬浮提示改成点按**：`Tip.vue` 监听 `touchstart` 切换显示，点提示以外的地方收起，点在按钮 / 输入框上时不弹（避免挡住操作）——因为手机没有鼠标悬停，而本作大量细节都放在悬浮提示里；
5. 顶栏在小屏只保留日期 / 评级 / 学生 / 资金速率（`.hide-mobile` / `.hide-tight`），通知条下移避免盖住顶栏；输入框在窄屏统一 16px，规避 iOS 聚焦自动放大。

验证方式：`tests/ui.test.ts` 里有一条用例把 `window.innerWidth` 设成 390，断言 `data-mobile` / `data-narrow` / `data-tight` 都命中、`--ui-scale` 为 1、`body.mobile-ui` 生效；手测时用浏览器 DevTools 的设备模拟（或本仓库开发时用 viewport 覆盖 390×844）即可。

- **淡入淡出**：所有居中弹窗（事件、效果卡三选一、剧情章节、评级考核、新解锁）统一 0.3 秒淡入淡出（遮罩淡入 + 面板轻微上浮）。样式集中在 `src/styles.css` 的 `.modal-fade-*`，改一处即可。
- **新解锁弹窗**：建筑落成、科技研究完成、评级考核通过、社团挂牌、校队组建、事件结算之后，引擎会把「当前已开放内容」和上一次快照做差集（`src/game/engine/UnlockEngine.ts`），只要有新内容就弹一个居中说明：标题是这次做了什么（例如「教学楼」落成），正文是一段校园味的剧情句，下面列出因此解锁的建筑 / 课程 / 科技 / 校规 / 活动 / 社团（带图标、类别与一句话说明）。
  - **课程槽位（课表）变多也算一次解锁**：教学楼、图书馆、实验楼、艺术楼、信息中心、音乐教室每升一级都会多一格课表槽位（公式 `courseSlots()`），所以「教学楼升级」这类操作即使没解锁别的条目，也会弹一句「课程槽位 +1（现在共 N 格）」。
  - 文案模板在 `UnlockEngine.ts` 的 `UNLOCK_FLAVOR`，按「建成 / 科技 / 评级 / 社团 / 校队 / 校规 / 事件」分句，改这里就能换语气。
  - 同一时刻只显示一个，其余排队；有「效果卡三选一」或剧情章节在显示时会让位，避免两层弹窗叠加。
  - 读档、传承与调试工具（解锁全部科技）只对齐快照、不弹提示。
- **仓储到顶不再弹提醒**：资源顶到上限时**不再**弹提示（早期版本会每隔两个游戏日刷一次「已达仓储上限」）。现在只靠右栏资源面板顶部的「⚠ N 项接近上限」标签、那一行说明，以及资源悬浮明细里的上限拆解来提示，不会打断游戏。

**处理时间**：事件不会被催着做决定。

- 游戏内期限：`150` 个游戏日（1× 速度下约 15 分钟现实时间）。
- 现实时间下限：无论游戏速度调多快，**至少保留 5 分钟现实时间**（`EVENT_MIN_REAL_SECONDS = 300`），只有「游戏时间到期」与「现实时间下限已过」同时满足才会自动结算。
- 游戏暂停时事件不会自动结束，浮窗上会直接写明「游戏已暂停，事件不会自动结束」。

**代价与后果**：每个选项都会列出结算明细（见下一节）。

### 事件选项的代价与后果预览

选项的说明不是手写文案，而是**把该选项的逻辑在一份状态副本上真的跑一遍，再对比前后差异**得到的结果（`src/game/engine/EventPreview.ts`），因此永远和实际结算一致：

| 显示 | 含义 |
| --- | --- |
| `代价：资金 -1200 · 教学资源 -300` | 会被扣掉的资源（按当前余额计算，含清零影响） |
| `获得：家长认可度 +15` | 会增加的资源 |
| `学生：满意度 +6.0 · 社交 +3.0` | 全校学生平均属性变化（含压力与满意度） |
| `教师：压力 +6.0` | 教师队伍平均变化 |
| `永久 学园祭评分 +3%` | 事件带来的永久加成 |
| `⏳ 2 天后进入下一阶段：课题进入关键期` | 延迟事件的后续安排 |
| `额外：3 张效果卡候选（三选一）` | 额外奖励 |
| `结算说明：…` | 事件逻辑本身返回的结算文字 |

由于预览是在当前存档上试算的，资源不足时它会显示真实结果（例如只有 300 资金时，「资金 -1200」会显示成 `资金 -300`），而不是一个付不起的数字。

延迟事件是经营感的来源：例如「教师提交科研项目」选择支持后，会在 2 天后出现「课题进入关键期」，此时可以追加设备投入（高回报）、按原计划收尾（稳健）或终止项目（止损但伤士气）。校舍维修工程同理。

事件可以设置标记位（`statistics.flags`），既用于成就，也用于条件事件的连锁。

## 十四、学年结算与校友

进入 9 月时生成**学校年度报告**：学术 / 体育 / 艺术 / 科研表现、学生满意度、教师士气、学校声望、比赛成绩、科研表现、毕业生人数、财务情况、年度奖项与建议。

同时结算：毕业生 → 校友（人数 + 质量 + 校友贡献）、教育基金拨付、完美学年统计、年度快照重置。

## 十五、学园传承与传承树

条件：评级 ≥ 52、累计毕业生 ≥ 200、（首次）至少 1 次比赛胜利。

收益：按评级、毕业生、比赛胜利、累计科研与已解锁成就计算传承点，同时积累校史点。

传承树七个分支（管理 / 教育 / 校友 / 体育 / 科研 / 国际 / 校史）共 36 个节点，传承点无法点满，因此形成流派。另有 6 个**传承特性**，提供永久能力而不是数值：

- 精英生源：新生基础属性更高
- 校友网络：每次学年结算自动获得校友贡献
- 竞赛强校：比赛奖励与成功率提升，开局即有体育馆
- 科研种子：开局解锁基础实验与科研训练
- 提前开放交流：开局解锁校际交流科技与图书馆
- 老校传统：每个学年开学典礼必定触发传统事件，开局拥有校史馆

## 十六、成就与统计

50 个成就分普通 / 隐藏 / 长期 / 极难，全部带实际奖励（传承点、资源或永久加成）。学校档案记录累计收入、培养量、毕业生、比赛、科研、交流、事件、卡片、传承、最长在线时长、历史最高学生数与最高评级。

## 十七、渐进式解锁

**校队面板（简洁模式 + 分组）**：列表按「**✅ 已成立 → 🏗️ 可以组建 → 🚫 暂时不能成立**」三组排列，条件满足后队伍会自动往上移。每行是一张两行的小卡片：第一行是图标 + **完整队名** + 项目标签 + 按钮，第二行是状态（已成立：`Lv.2 · 实力 34 · 士气 72 · 6 胜 2 负`／训练或比赛进行中；可以组建：`起步实力 X · 需要学生活跃度 Y`；未满足：`还差：轻音社 Lv.3（当前 Lv.1）、音乐教室 Lv.1`）。按钮最多两个：主按钮（训练 / 上报成立）+「详情」；训练消耗、扩编成本、战绩、组建花费、推荐队名等细节在悬浮提示里，改名 / 组建选名 / 赛事报名在选中队伍的详情区完成（赛事同样是一行一个「参赛」按钮 + 悬浮明细）。

开局只有【总览】【建筑】【选项】三个标签，其余系统由下面的剧情引导一章一章开放。

### 剧情引导（15 章）

新存档与每一次「学园传承」之后，都会从第一章重新播放一段剧情，用故事把系统一章一章交给你：

| 章 | 触发（＝任务面板里的「要做的事」） | 内容 / 解锁 |
| --- | --- | --- |
| 一 · 一封信 | 开局 | 远房亲戚的信与那张操场上的照片 → 引导去【建筑】升级教学楼 |
| 二 · 只剩几位老师 | 建成 / 升级第一栋建筑 | 教务处名单 → 解锁【课程】【学生】，引导去开课 |
| 三 · 第一张课表 | 开设第一门课 | 走廊上的读书声 → 解锁【科技】 |
| 四 · 教研与改革 | 完成第一项科技 | 第一次教研会 → 解锁【校规】 |
| 五 · 规矩的代价 | 施行第一条校规 | 校规上墙、说明事件的代价与后果 → 解锁【事件】 |
| 六 · 走廊上的声音 | 处理完第一件事件（剧本事件「开学第一周」自动弹出） | 校长室的门关不上 → 解锁【活动】 |
| 七 · 别人的学校 | 建成 3 栋建筑 | 邻校联赛邀请 → 解锁【社团】 |
| 八 · 第一场比赛 | 参加过第一次比赛 / 交流 | 大巴车上的歌声 → 解锁【校队】 |
| 九 · 三点半以后 | 成立第一个社团 | 部活的钟声 → 解锁【统计】【交流】 |
| 十 · 校队 | 成立第一支校队 | 「我们想去外面比一场」 |
| 十一 · 毕业那天 | 第一次学年结算 | 毕业那天 → 解锁【成就】 |
| 十二 · 走出校门 | 校际 / 国际交流科技 | 来访的学校 → 解锁【传承】 |
| 十三 · 做过的事 | 第一个成就 | 荣誉墙上的照片 |
| 十四 · 传承 | 评级 ≥ 40 或毕业生 ≥ 100 | 老校长的笔记本 |
| 十五 · 自由经营 | 评级 ≥ 52 且毕业生 ≥ 200 | 之后没有剧本，校史由你写 |

规则：

- **任务文案与触发条件必须一一对应**：`objective` 就是「让这一章翻页要做的事」，`trigger` 是它的达成条件；故事在该章达成时弹出，所以故事结尾要引出**下一章**的任务（改内容时守住这条，任务面板才不会指向做不到的事，`tests/tutorial.test.ts` 里有对应检查）。
- 每一章的浮窗上都有「不再显示教程」；【选项】里也有「显示剧情引导」开关与「重看剧情引导」按钮；
- **关掉教程不会影响解锁**——系统仍会在同一条件到达时自动开放，只是不再弹窗；
- 剧情是顺序推进的（一章读完才检查下一章），因此不会一次弹出多个窗口。
- **界面上有常驻的任务面板**（左栏顶部「🧭 剧情引导」）：显示当前是第几章、这一章要做什么、以及「前往」按钮直接跳到对应标签。全部走完后换成老校长的一句话（可以收起）。
- **随机事件在剧情引导期间不出现**：引导阶段只会派发剧本事件（`demoEvent`，例如「开学第一周」），玩家处理完第一件事件之后随机事件才恢复，因此一开局不会被突发情况打断。

### 评级考核（每次升级都要过评估）

评级不再是「数值够了就自动升档」。学校要经过评估组的一次现场考核，才能进入下一等级：

```
已通过等级 ratingTier → 评级显示上限 = 下一等级门槛 − 0.1
未考核前：评级数值被锁住，涨不上去
未受限的评级达到门槛 → 触发考核 → 评估组带清单来学校
清单全部达成 → 提交考核 → 等级提升 + 上级奖励
```

| 等级 | 门槛 | 考核（评估方） | 清单示例 |
| --- | --- | --- | --- |
| 待整改高中 | 0 | — | 开局就是这一档 |
| 普通高中 | 20 | 办学基本条件核查（区教育局督导组） | 学生 ≥ 140、平均学术 ≥ 28、教学楼 Lv.2 |
| 区级示范高中 | 35 | 区级示范高中评定 | 学生 ≥ 180、学术 ≥ 33、教师 ≥ 18 且能力 ≥ 48、图书馆 Lv.2、2 项科技 |
| 市级示范高中 | 50 | 市级示范高中评定（市教育局评估中心） | 学生 ≥ 260、学术 ≥ 40、体育/艺术/科研任一 ≥ 38、6 项科技、4 个社团、3 次比赛胜利 |
| 省级重点高中 | 62 | 省级重点中学评估委员会 | 学生 ≥ 350、学术 ≥ 50、毕业生 ≥ 200、12 项科技、8 个社团、12 次比赛胜利 |
| 全国名校 | 74 | 国家教育评估专家组 | 学生 ≥ 500、学术 ≥ 60、科研 ≥ 55、毕业生 ≥ 600、20 项科技、打入全国大赛 |
| 国际知名实验校 | 86 | 国际教育交流评审团 | 学生 ≥ 700、学术 ≥ 70、国际声誉 ≥ 300、30 项科技、举办过学园祭 |
| 世界实验标杆校 | 95 | 国家教育评估委员会 | 学生 ≥ 900、学术 ≥ 80、影响力 ≥ 500、毕业生 ≥ 2000、完成过传承、社团等级总和 ≥ 30 |

每次考核都有独立的剧情文本（督导组、评估委员会、海外观察员……）、清单与奖励（教育基金 / 声望 / 影响力）。考核进行中会在任务面板与浮窗里同时提示，未完成的项会被打回来。

### 校队命名

校队名不再写死，而是由**学校名 + 队伍后缀**生成：学校叫「星丘」，篮球队就会推荐「星丘火鸟队」「星丘苍鹰队」「星丘流星队」「星丘篮球队」等名字。

- 每支队伍都有 6 个备选后缀（`namePool`），界面上点一下即用；
- 也可以自己写，最多 24 字；
- 成立之后随时可以「✏️ 改名」。

### 现实时间显示

所有资源速率的单位都是**现实时间**：右栏资源面板、顶栏、课程面板显示的都是「每现实分钟」的收支。鼠标移到顶栏的 💰 / 📚 上会摊开每一项来源（学费、建筑、薪资、维护…）。

```
1 现实秒   ≈ 0.08 × 速度 游戏日      （1× 时）
1 现实分钟 ≈ 5 × 速度 游戏日         （1× 时 = 5 游戏日）
```

例如开局资金约 +4.2K/现实分钟、教学资源约 +4.0K/现实分钟（1×）；课程消耗与产出同样按现实时间显示，方便和仓储上限、离线收益直接对照。注意游戏时钟很快（1 游戏日 ≈ 12 现实秒），所以「每分钟」的数字看着大，但受仓储上限约束，实际能攒下的仍是上限那么多。
